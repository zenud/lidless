lidless Source on GitHub

The eye that never closes.

lidless keeps your Mac awake for as long as you say, even with the lid shut, then puts sleep back the way it was.

Install

Needs macOS 12 or later and, for the menu bar button, Homebrew.

git clone https://github.com/zenud/lidless.git
cd lidless
./install.sh

The installer asks for your password once, to set up the service that does the work. After that, nothing does. It also copies the command to ~/.local/bin, installs SwiftBar if it is missing, and drops the button into it. Add --no-button to skip the button.

Try the button

A moon sits in your menu bar. Pick a duration and it turns into an eye with the end time next to it. This one works on the page.

  • Keep the Mac awake for…
  • Awake until
  • Restart for…

The real one comes back by itself after a restart.

Or type it

lidless
Stays awake for 2 hours.
lidless 4h
4 hours.
lidless 90m
90 minutes.
lidless noend
Until you stop it.
lidless stop
Ends the session and restores sleep.

It prints the end time and returns straight away: close the Terminal window, the session carries on. lidless stop ends it.

What it does to your Mac

The command and the button only write an end time into a file. A service that macOS starts by itself runs pmset -a disablesleep 1, the macOS setting that forbids sleep altogether, waits, then runs pmset -a disablesleep 0. That setting belongs to administrators, so the service runs as one. Nothing else is touched.

Before you close the lid

With the lid closed, a Mac runs hot and drains its battery. Plug it in and leave it on a clear surface, never in a bag.

  • The display can still turn off. Only the system stays awake.
  • Nothing watches the battery or the temperature for you.
  • Any user account on the Mac can start or stop a session, with no password.

Uninstall

sudo launchctl bootout system/io.github.zenud.lidless
sudo rm /Library/LaunchDaemons/io.github.zenud.lidless.plist /Library/PrivilegedHelperTools/lidless /var/db/lidless
rm ~/.local/bin/lidless
rm ~/.swiftbar/lidless.30s.sh
